# Yuta Hirahata — Portfolio

A portfolio presenting my work across product, HCI, and computer graphics.

**Live site:** https://patabasket.github.io/portfolio/

Built with HTML, CSS, and JavaScript. Deployed to GitHub Pages from `public/` by GitHub Actions.

## Preview locally

```powershell
python -m http.server 4173 --directory public
```

Then open <http://localhost:4173/portfolio/>.
